# Code of Conduct

## Our Standards

This project is a professional engineering environment. Expected behavior:

- Use welcoming and inclusive language
- Respect differing technical viewpoints and approaches
- Accept constructive feedback on code and design
- Focus on what is best for the project
- Show empathy toward other contributors

Unacceptable behavior:

- Personal attacks or insults in code reviews, issues, or discussions
- Harassment or discriminatory language
- Publishing others' private information without consent
- Dismissing security vulnerability reports

## Enforcement

Violations can be reported to npoluri1@gmail.com. Reports will be reviewed promptly and handled confidentially.

## Scope

This Code of Conduct applies to all project spaces: GitHub issues, pull requests, code reviews, and any communication related to this project.
